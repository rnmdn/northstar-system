# Soft-skills UI preview

Open http://127.0.0.1:8766/soft-skills.html while the local server is running. This standalone preview contains 12 researcher-drafted scenarios (three per communication, teamwork, problem-solving and adaptability area). These are illustrative original drafts, not items reproduced from or validated by the cited SJT literature.

Selection, Back/Next, skipping, flags, area navigation, grouped review and preview completion work locally. Responses use an isolated sessionStorage key and are not account-synced, scored or included in the Random Forest. Finishing is a walkthrough action, not a submitted assessment.

A separate database-backed pilot now exists at `soft-skills-assessment.html`, with the question editor at `question-editor.html`. See QUESTION-BANK.md. The preview stays independent and unscored. Before publishing the pilot, obtain faculty review of construct alignment, scenario realism, response options and scoring; pilot with students and establish score interpretation. Decide where the module belongs in the main assessment journey.
