# Score-based learning plan

Implemented 13 October 2026. Policy: learning-start-v1, in scripts/learning-plan.js.

## Resource-selection rules

Each selected career uses its authoritative knowledge /6, practical /4 and written /4 scores. All three must be graded. Total 0–5 selects Foundations; 6–10 selects Build your skills; 11–14 selects Explore a challenge. These thresholds are provisional learning-start rules, not validated proficiency bands, experience labels or professional credentials. Pending or invalid totals produce Awaiting scores, not zero.

Compare component points divided by each component maximum. The lowest fraction suggests the focus. Ties prioritize practical work, then written reasoning, then knowledge. A perfect 14/14 does not imply a weak component; it suggests a less-guided project. AI fallback grades carry a visible caveat that code was not executed. Interests and RF percentages do not determine learning starts.

Catalog content contains authored activities for all six careers at all three starting points. Some levels share a learning source but change the guidance and independence of the practice activity. The catalog recommends a resource and an activity, not a claim that the external course has the same level label. Networking retains a fundamentals reference across levels, paired with progressively less-guided simulated tasks.

## Implementation and verification

Curated HTTPS URLs are supplied by the catalog, never generated by AI. External links open with noopener/noreferrer and accessible new-tab labels. Optional reflections retain the existing encrypted persistence. The catalog does not modify grading, submitted answers, the RF mapping, or probabilities and consumes no Gemini calls.

Tests cover boundaries 0/5/6/10/11/14, missing scores, relative component strengths, resources for all careers/levels and reflection saving. Browser checks covered desktop, 390px mobile with no horizontal overflow, and the Learn / Practice / Reflect layout using a fictional profile.
